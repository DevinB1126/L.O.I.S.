# LOIS v1 Roadmap

## Current Status

LOIS is now a local AI assistant application with:

- React HUD interface
- Node/Express backend
- Ollama local AI model
- LOIS and IGNIS modes
- Persistent memory
- Conversation history
- Goals
- Calendar v1
- Voice input
- Voice output
- LOIS blue theme
- IGNIS red/orange theme

---

## LOIS v1 Goal

Build a local, voice-enabled personal AI assistant with memory, goals, calendar, and a futuristic HUD interface.

## Development Rule

LOIS v1 should stay focused on:

- Voice
- Memory
- Goals
- Calendar
- HUD experience

Anything related to smart home, robotics, full computer control, or production IGNIS should wait until after LOIS v1.
